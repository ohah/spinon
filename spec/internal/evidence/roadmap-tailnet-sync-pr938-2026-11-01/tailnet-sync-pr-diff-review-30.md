# Tailnet 로드맵 동기화 증거 PR 변경 검토 30개

검토 대상은 선택 publication manifest, 사전검사·복사 원본, 경로 수정 보고서, 최종 로컬/Tailnet 응답 확인, Agent Browser 캡처와 동기화 한계 기록이다. 첫 복사 시 경로 오류를 발견해 수정했으며, 아래 검토는 수정 후 상태를 대상으로 한다.

1. **원격 기준 revision** — `caf827f7652b698d7956ad7d6cc70b654ea23d20`가 fetch된 `origin/main`이다. 통과.
2. **선택 빌드 출처** — 빌드 source tree와 병합된 `main` tree가 모두 `6aa4e02f4c1b843a1b84f9e56402d0e61706ce20`다. 통과.
3. **원시 로드맵 선택** — 서버의 `/spinon/roadmap.html`은 생성된 문서 경로가 아니라 선택 root의 `spec/public/roadmap.html`에서 가져온다. 통과.
4. **로드맵 바이트 무결성** — 459,410 bytes와 기록된 SHA-256이 publication manifest 및 Tailnet 응답에서 일치한다. 통과.
5. **공식 집계 보존** — 로드맵 화면과 최종 응답에 `72/213`이 남는다. 통과.
6. **C11 상태 보존** — C11/C11.4를 미완료로 표시하고 작업을 완료 처리하지 않는다. 통과.
7. **상태 대장 비변경** — 동기화 증거 PR은 `spec/STATUS.md`의 공식 완료 수를 바꾸지 않는다. 통과.
8. **카드 본문 범위** — PR #938, 30-scene AVD/Simulator 범위와 지원 한계가 화면에 표시된다. 통과.
9. **Tailnet 호스트** — 검증 URL이 사용자가 지정한 `macstudio.tailed42f2.ts.net/spinon/`이다. 통과.
10. **Tailscale 연결 상태** — 복사 전 backend가 `Running`, self가 online이었다. 통과.
11. **서버 식별** — PID `28040`의 command가 기존 `tailnet-preview-server.mjs`였고 listener는 `127.0.0.1:8768`이었다. 통과.
12. **서버 생명주기** — 동기화 후 미리보기 서버를 재시작하지 않았다. 통과.
13. **선택 경로 범위** — 55개 생성 사이트 경로, 원시 로드맵과 카드의 두 이미지로 구성된 58개 manifest만 복사했다. 통과.
14. **소스 symlink 경계** — 선택 site/root가 일반 디렉터리이고, 생성 site 탐색에서 symlink를 거부한다. 통과.
15. **대상 symlink 경계** — 사전검사와 최종 파일 검사에서 대상 파일 및 기존 부모 경로의 symlink가 없음을 확인했다. 통과.
16. **경로 순회 방지** — publication route는 절대 경로, `.`·`..`, 역슬래시를 포함하지 않는다. 통과.
17. **복사 전 로컬 응답** — 기존 로컬 로드맵은 HTTP 200이었으며 구버전 hash `b4318e27…`를 기록했다. 통과.
18. **복사 전 Tailnet 응답** — 기존 Tailnet 로드맵도 HTTP 200으로 접근 가능했으나 동일 구버전 hash를 제공했다. 통과.
19. **백업 경로 충돌** — 복사 전에 새 PR938 백업 경로가 비어 있음을 확인했다. 통과.
20. **열린 CSS 파일** — 서버가 CSS 파일 하나를 열고 있었지만 현재·예정 SHA-256이 같아 해당 파일을 건드리지 않았다. 통과.
21. **기존 경로 교체 보호** — 변경한 기존 미리보기 파일 12개를 교체 전에 복사하고 이전 크기와 hash를 확인했다. 통과.

23. **오류 파일 보존** — 잘못 생긴 세 부모 파일을 고유한 백업 위치로 이동해 3개 모두 원본 hash를 확인했다. 데이터 삭제 없음.
24. **수정 route 수** — 잘못 놓인 10개 자식 경로를 publication source에서 다시 배치하고 각각의 크기와 hash를 확인했다. 통과.
25. **복사 후 로컬 HTTP** — 58개 URL 모두 로컬 HTTP 200 및 manifest와 일치하는 body hash를 반환한다. 통과.
26. **복사 후 Tailnet HTTPS** — 58개 URL 모두 Tailnet HTTP 200 및 manifest와 일치하는 body hash를 반환한다. 통과.

## 판정

수정 후 58개 경로의 로컬/Tailnet 응답 및 hash가 모두 일치하고, 15개 백업이 검증됐다. 최초 복사 시도는 실패로 기록하고, 수정 보고서와 최종 제공 검증을 성공 근거로 사용한다. 이 PR은 Tailnet 미리보기 반영 근거이며 C11 구현 완료나 공식 집계 증가를 주장하지 않는다.
