# Tailnet 로드맵 완료 수 원본 확인

**확인일:** 2026-10-16 · **상태 대장 기준 main:** `bd84a70c90d83c75ad31f273d3ebd37fa2a349f3`

## 관찰

Agent Browser로 [Tailnet 구현 로드맵](https://macstudio.tailed42f2.ts.net/spinon/roadmap.html)을 열었다. 화면의 읽기 전용 집계는 `197개 표시 · 공식 완료 62/197`이며, 동기화 설명은 `상위 78개 + 세부 ID 117개 + ID 없는 하위 체크 2개`라고 표시한다. DOM에는 체크박스 197개가 있고 모두 비활성화돼 있다. 체크된 62개는 모두 접근성 이름에 `공식 완료`가 포함된다. 브라우저 localStorage와 sessionStorage에는 항목이 없었다.

화면 캡처: [Agent Browser 화면](roadmap-status-counter-2026-10-16/roadmap-agent-browser.png)

## 원본 대조

`spec/public/roadmap.html`은 `https://api.github.com/repos/ohah/spinon/contents/spec/STATUS.md?ref=main`에서 상태 대장을 가져온다. 요청에 `cache: 'no-store'`를 쓰고 체크 상태를 읽기 전용 입력에 반영한 뒤 표시 항목 기준 집계를 만든다. 오류가 나면 상태 미판정 문구를 표시한다. 따라서 이 페이지의 체크 수는 개인 브라우저 저장 상태가 아니다. 공식 판정은 계속 `spec/STATUS.md`의 항목과 연결 근거를 따른다.
