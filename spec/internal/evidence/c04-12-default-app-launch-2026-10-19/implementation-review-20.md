# C04.12 기본 앱 launch 구현 적대적 검토 20개

2026-10-19, 계획 검토와 분리해 실제 구현 코드와 Android/iOS Simulator 실행·release artifact를 대상으로 새 실패 경로 20개를 검토했다. 각 항목은 서로 다른 route, 생명주기, 환경, 렌더링, 빌드 경계를 다룬다.

## 검토 범위와 남은 경계

이 검토는 제한된 `examples/bootstrap/index.html`/`root-app.js` 기본 화면, Android API 37 ARM64 AVD, iPhone 17 Pro와 iPad Pro iOS Simulator, macOS arm64 product/fixture-positive staticlib에 한정된다. 물리 기기, Android PixelCopy, iOS compositor 이후 drawable readback, 전체 HTML/CSS 또는 전체 fixture family의 mobile linked-artifact 부재는 검증하지 않았다. C04.12/C15/C16/C19 전체 구현 완료를 뜻하지 않는다.
