# C04.12 기본 앱 launch PR 변경분 적대적 검토 30개

2026-10-19, PR #326의 Android/iOS 기본 launch, root Canvas clear, WGPU 전달 경로, fixture 분리와 빌드 도구 변경을 서로 다른 실패 관점으로 검토했다. 검토 중 Android의 false-valued `spinon_*` extra가 기본 GPU 경로를 막는 결함을 재현해 수정하고, Android API 37 AVD에서 수정 APK를 다시 실행했다. 계획 검토 20개와 구현 검토 20개를 이 검토에 재사용하지 않았다.

## 판정과 한계

검토 중 발견한 false-valued Android extra 결함은 수정했다. 해당 입력을 수정된 APK에 전달해 기본 route, `root_app_marker=ready`와 화면을 확인했다. 현재 PR은 화면 pixel 표본을 포함한 제한된 Android API 37 AVD 및 iOS 26.2 Simulator 경로로 한정한다. 물리 기기, hardware GPU, Android PixelCopy, iOS compositor 이후 readback, sRGB target format 실행, opacity group 장면은 검증하지 않았다. C04.12/C15/C16/C19 전체 완료 판정은 아니다.
