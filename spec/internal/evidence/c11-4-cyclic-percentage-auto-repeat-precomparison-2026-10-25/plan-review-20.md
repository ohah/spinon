# C11.4 cyclic percentage auto-repeat 계획 검토 · 2026-10-25

**검토 대상:** <a href="/spinon/plan/c11-4-cyclic-percentage-auto-repeat.html">계획</a>과 이 디렉터리의 사전 비교 자료. 계획 검토이며 Spinon runtime 동작을 검증하지 않는다.

## 전체 결과

Intrinsic pass에서 auto-repeat을 한 번 계산해 24px max-content 폭을 구한 뒤 definite 24px pass에서 두 번 반복해 최종 track `[12px,12px]`을 만드는 기대값은 CSS Grid 2025 CRD에 부합한다. 40px control의 `[20px,20px]`도 독립적으로 계산된다. Evidence는 Chrome 156 값을 관측 결과로 분리하고, 최종 CSSOM만으로 앞선 intrinsic count를 증명할 수 없다고 명시한다.

최초 검토에서는 24px intrinsic 폭 산식, 대표적인 거부 입력, parallel orthogonal-row 후보와 공유할 trace/router/host 파일의 소유 순서를 더 구체화하도록 요청했다. 최초 결과는 **14 PASS / 6 PARTIAL / 0 FAIL**이며, 아래 표에는 수정 전 판정을 그대로 보존한다. 후속 절은 수정된 계획과 evidence를 다시 확인한 독립 결과다.

**주요 1차 출처:** [CSS Grid Layout Module Level 1, 2025 CRD](https://www.w3.org/TR/2025/CRD-css-grid-1-20250326/) §§6.2, 7.2.1, 7.2.3.1–7.2.3.2, 11.1, 11.2, 11.5–11.6; [CSS Box Sizing Module Level 3, 2026-09-04 WD](https://www.w3.org/TR/2026/WD-css-sizing-3-20260904/) §2. 두 문서는 각각 Candidate Recommendation Draft와 Working Draft로, W3C가 작업 중 문서임을 밝힌다. CSS Sizing §2는 max-content 같은 intrinsic sizing keyword가 indefinite size라고 정의한다.

## 판정

수정된 계획/evidence에서 최초 여섯 항목의 계획 결함은 모두 해소됐다. #3·#19의 런타임 validator와 feasibility gate는 아직 실행되지 않았고, 특히 #19에서 semantic phase, pass별 repeat count와 percentage basis를 실제 호출부 값으로 얻지 못하면 구현을 중단해야 한다. 그 gate가 통과했다고 추정하거나 Chrome CSSOM으로 대체하면 안 된다. 이 검토에서는 Agent Browser, Spinon runtime, Android 또는 iOS를 실행하지 않았다. 계획의 geometry 기대값은 그대로 두며, 이 문서는 구현 승인이나 C11.4/72/213 완료 증거가 아니다.
