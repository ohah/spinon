# C11.3.3 grid-template-areas 구현 실패 관점 검토 · 2026-10-14

계획의 sparse rectangle 선택과 Chrome precomparison 검토와 별개로, 구현 후보의 실패 경계를 확인한다. 이 문서는 구현 검토 20개 관점이다. `PASS`는 적힌 제한 fixture/code boundary만 검사했다는 뜻이며 C11.3.3 전체 완료를 뜻하지 않는다.

## Gate

JavaScript 2/2, CSS reference 412/412, R05 benchmark 29/29, Rust workspace 690 passed·4 ignored·0 failed가 통과했다. workspace/fixture-feature Clippy, rustfmt/diff, FFI feature test와 default/opt-in release artifact 경계도 통과했다. C11.3.3 도구 검사는 CSS reference suite 안에서 11/11 통과했다. 통합 회귀의 원래 실패는 병렬 실행 중 fake ADB test shim의 시작 경합이었다. `#!/usr/bin/env node`가 Node를 exec하는 사이 host `ps`가 다른 command identity를 관찰해 안전한 종료가 신호 전송을 거부했다. shim을 `process.execPath`로 직접 실행하도록 바꿨고 collector별 identity 오류를 shutdown 메시지에 보존했다. 원래 실패는 `full-regression-before-fix.log`에 남겼다. 현재 소스의 통합 `bun run test` 결과는 [회귀 로그](./c11-3-3-grid-template-areas-runtime-2026-10-14/full-regression-after-avd-routing-fix.log)에 있다.

iPhone 17 Pro/iOS 26.2 Simulator와 사용자가 허용한 Android API 37.0 ARM64 AVD에서 성공·기대 거부 scene을 각각 실행했다. 두 환경 모두 고정 geometry와 일치했고 표면 표본 2/2가 exact였다. AVD는 알 수 없는 scene을 runtime 평가·GPU draw 전에 거부했다. renderer는 ANGLE/Vulkan/SwiftShader이며 SM-S731N 실기기와 hardware GPU는 확인하지 않았다. 이 초기 검토 시점에는 전체 runtime matrix가 남아 있었다. 뒤이어 최신 source AVD에서 26 scene·65 node matrix를 실행해 성공 19·cascade fallback 5·기대 거부 2, visible geometry 오차 0 CSS px 및 PixelCopy 2/2 exact를 확인했다. 최신 iOS Simulator run은 success/rejection 2 scene과 4 success frame, Metal 2/2 exact다.
