# Android AVD 수집기 적용 차이

Android 실기기 전용 수집기를 API 37 AVD에 적용하기 위해 임시 실행 사본에서 대상 기기 종류 검사와 결과 label만 AVD로 바꿨다. 장면 목록, 앱 바이너리, 실행 경로, geometry 비교, 오류 진단, PixelCopy 표본 수집 및 검증 조건은 바꾸지 않았다. 저장소의 실기기 전용 수집기 파일은 수정하지 않았다.

실행 명령과 기기 식별은 [matrix-command.log](./matrix-command.log), 상세 결과는 [comparison.json](./comparison.json)에 있다.
