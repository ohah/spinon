# PR #414 로드맵 변경 검토 30항목

1. `PR #413` 링크가 합쳐진 검증 근거를 가리킨다.
2. merge SHA가 현재 `origin/main`의 병합 커밋과 일치한다.
3. 상태 대장에 이미 기록된 150-scene 근거를 요약한다.
4. 150은 서로 다른 fixture scene의 수로 설명된다.
5. PixelCopy 42/42는 선택 표본으로 한정한다.
6. `SurfaceView` 표본 범위를 일반 화면 검증으로 넓히지 않는다.
7. frame과 track trace가 검사됐다는 표현이 근거와 일치한다.
8. draw/present를 광학적 표시 보장으로 확대 해석하지 않는다.
9. PNG texel painting 한계를 명시한다.
10. CSS border stroke의 전체 픽셀 정확성을 주장하지 않는다.
11. WPT 적합성 주장을 하지 않는다.
12. 일반 CSS Grid 지원 완료를 주장하지 않는다.
13. C11.4 완료 체크를 변경하지 않는다.
14. 공식 완료 집계의 증가를 주장하지 않는다.
15. 결과를 Samsung SM-S731N 단일 기기로 한정한다.
16. Android 16/API 36 정보를 근거와 맞춘다.
17. 화면 링크가 존재하는 overflow PNG를 가리킨다.
18. README 링크가 선택된 RSPress root의 경로 규칙과 맞는다.
19. 링크에 공백·잘못된 경로 구분자가 없다.
20. 외부 PR 링크가 저장소의 실제 PR 번호를 가리킨다.
21. HTML anchor 요소가 서로 중첩되지 않는다.
22. 새 문단이 `kanban-note`의 기존 스타일을 재사용한다.
23. 문서 언어가 프로젝트 한글 규칙을 따른다.
24. 임시 또는 실험용 URL을 공개 경로로 노출하지 않는다.
25. 기존 C11.4 multi-span 기록을 대체하거나 삭제하지 않는다.
26. 기존 C11.3.3 및 다른 항목의 텍스트를 바꾸지 않는다.
27. 제품 코드와 API 계약을 건드리지 않는다.
28. 실행 실패와 재시도 이력을 숨기지 않는다.
29. 상태 미완료의 이유와 잔여 범위가 독자에게 보인다.
30. PR #413 증거, 현재 source revision, Tailnet preview에 걸쳐 출처를 추적할 수 있다.
