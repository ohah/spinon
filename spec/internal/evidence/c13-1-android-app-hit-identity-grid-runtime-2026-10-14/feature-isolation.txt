# FFI fixture feature isolation · 2026-10-14

대상은 host macOS debug 정적 라이브러리 `target/debug/libspinon_ffi.a`다. 이 검사는 final APK 또는 release artifact 크기를 판정하지 않는다.

## 기본 조합

명령: `cargo build --locked -p spinon-ffi --lib`

Rust 1.96.1 / LLVM 22.1.2 산출물용 `llvm-nm`과 `strings`를 사용했다.

- `spinon_runtime_gpu_host_new_c13_1_compact_surface_matrix_fixture`, `spinon_runtime_gpu_host_eval_c13_1_compact_surface_matrix_fixture`, `hit_identity_grid_summary_json`: 없음
- `elementFromPoint(xCssPx, yCssPx), x=0..299`: 없음
- `cargo tree --locked -p spinon-ffi -e normal`의 `sha2`: 없음

## fixture 양성 대조

명령: `cargo build --locked -p spinon-ffi --lib --features c13-1-overflow-clip-fixture-test`

- 두 C13.1 compact surface matrix FFI 심볼과 Rust `hit_identity_grid_summary_json` 심볼: 있음
- 고정 grid query convention 및 summary payload 문자열: 있음
- `cargo tree --locked -p spinon-ffi -e normal --features c13-1-overflow-clip-fixture-test`: `sha2 v0.11.1` 있음

따라서 이 host debug archive의 기본 feature 조합에서는 신규 fixture symbol·payload·SHA-256 의존성이 빠지고, 전용 fixture-test 조합에서만 포함된다.
