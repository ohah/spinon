# 로드맵 진행 상태 화면 적대적 검토 20개

범위는 C11.4 진행 상태의 가시성, 완료 집계 분리, 실제 Tailnet 브라우저 화면이다. 이 검토는 전체 Grid 구현 완료나 전체 문서 링크 적합성을 판정하지 않는다.

1. **완료로 오표기:** C11.4가 상위 완료 항목으로 승격되지 않았는가? — 통과. 활성 작업으로만 표시한다.
2. **완료 수 증가:** 사용자 정의 진행 카드가 `78/214`를 변경하지 않는가? — 통과. 화면과 공식 상태 값 모두 78/214다.
3. **완료·진행 혼동:** 진행 중 세부 작업과 공식 완료가 별도 지표임을 설명하는가? — 통과. 보드 안내와 상태 카드가 설명한다.
4. **영어 전용 레이블:** 한국어 사용자가 활성 작업을 놓치지 않는가? — 수정 통과. 헤더 `진행 중: C11.4 Grid 트랙 크기`와 카드 한글 제목을 표시한다.
5. **상태 식별:** 카드에 C11.4 코드와 진행 상태가 모두 있는가? — 통과. `C11.4 · 진행 중`.
6. **컬럼 누락:** 활성 카운트가 0이 되거나 할 일 칼럼에만 표시되지 않는가? — 통과. Browser DOM에서 진행 중 `1/2`.
7. **카드 잘림:** 1120px 보드의 카드 제목 truncation이 한국어 제목을 잘못 자르지 않는가? — 통과. `Grid 트랙 크기`가 전체 표시된다.
8. **초기 HTML 상태:** JS 전 초기 상태가 서버 완료로 오해되지 않는가? — 통과. `공식 상태를 불러오는 중` 표시는 유지되며 진행 상태 문구는 별도로 정적 노출한다.
9. **상태 API 실패:** GitHub API 실패 때 C11.4 표식도 사라지는가? — 코드 검토 통과. 정적 진행 헤더와 이력 카드는 남고 동기화 오류는 별도 표기한다. API 장애 주입은 실행하지 않았다.
10. **API 완료 데이터 왜곡:** 공식 API 완료 상태가 로컬 진행 카드에 완료를 덮어쓰는가? — 통과. `C11.4` 세부 진행 배열과 공식 상태 맵은 별도다.
11. **WIP 한도 표시:** 활성 작업 한도 `1/2`가 현재 카드 수와 일치하는가? — 통과. 활성 세부 카드 하나다.
12. **과다 활성 작업:** 대기 R02/R05/R08이 진행 카드로 합산되는가? — 통과. 별도 외부 대기 열에 3개로 보인다.
13. **데스크톱 문서 overflow:** viewport 밖 가로 overflow가 생기는가? — 통과. 1440 CSS px viewport, document/body 모두 1440.
14. **모바일 문서 overflow:** 390px viewport에서 페이지 자체가 넓어지는가? — 통과. document/body 모두 390px.
15. **모바일 보드 접근성:** 가로 보드의 진행 카드를 볼 수 있는가? — 통과. 칸반을 활성 열로 272px 이동한 화면에서 카드가 완전히 보인다.
16. **모바일 헤더 가시성:** 보드를 옆으로 밀어도 진행 상태를 유추할 수 있는가? — 통과. 보드 밖 헤더에 C11.4 진행 상태가 남는다.
17. **모바일 제목 줄바꿈:** 제목과 진행 레이블이 겹치거나 잘리는가? — 통과. 390×844 Agent Browser 캡처에서 세로 배치로 읽힌다.
18. **카드의 최신 근거:** 진행 상태 설명이 병합된 PR #1277과 어긋나는가? — 통과. 최신 병합 slice와 다음 intrinsic-size oracle 순서를 표시한다.
19. **끊어진 직접 경로:** 카드의 계획·비교·실행·review·이 작업 근거가 404인가? — 통과. Agent Browser 다섯 페이지 렌더, 로컬·Tailnet HTTP 200.
20. **표본 과장:** screenshot을 PixelCopy/Metal readback 또는 CI pass라고 부르는가? — 통과. roadmap과 기존 상세는 surface readback 아님, CI rollup 없음, C11/C11.4 미완료로 기록한다.
