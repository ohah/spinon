# C12.4 Tailnet 동기화 PR 변경 검토

범위는 선택 문서 빌드 결과, Tailnet 미리보기 복사 기록, 응답 해시 검증, Agent Browser 캡처와 설명 문서입니다. 런타임 코드는 변경하지 않습니다.

1. **원본 revision** — 원본 commit이 병합된 PR #330의 main commit `63cfe6e`와 일치하는지 확인한다.
2. **빌드 버전** — Rspress 2.0.22 고정 버전을 사용했는지 build log에서 확인한다.
3. **선택 빌드 범위** — 결과를 전체 문서 빌드로 오인하지 않도록 README와 로그를 분리해 둔다.
4. **dead-link 옵션** — 선택 빌드에서만 검사를 끈 사실과 전체 빌드 오류를 함께 공개한다.
5. **manifest 범위** — 입력 manifest의 후보 수가 92이며 경로가 저장소 상대 경로인지 확인한다.
6. **집계 산술** — 신규 57 + 교체 6 + 동일 29가 전체 92와 맞는지 확인한다.
7. **교체 파일 허용 목록** — 변경 가능한 기존 파일이 정확히 6개이며 사전 집계와 일치하는지 확인한다.
8. **동일 파일 처리** — 동일 29개 파일을 불필요하게 다시 복사하지 않았는지 확인한다.
9. **삭제 방지** — 사전 검사에서 삭제 0개인지 확인한다.
10. **백업 순서** — 교체 파일의 백업이 대상 덮어쓰기 전에 만들어졌는지 확인한다.
11. **백업 완전성** — 교체 대상 6개가 모두 백업되고 SHA-256이 대조됐는지 확인한다.
12. **백업 실패 경로** — 백업 실패 수와 삭제 수가 모두 0인지 확인한다.
13. **복사 수** — 실제 신규·교체 복사 63개가 57 + 6과 일치하는지 확인한다.
14. **전체 복사 후 검증** — 복사 뒤 92개 전부의 해시를 다시 확인했는지 검사한다.
15. **복사 실패 경로** — 복사 단계 실패 수가 0인지 확인한다.

17. **HTTP 상태** — 184개 응답이 모두 200인지 확인한다.

19. **비공개 호스트 처리** — Tailnet 호스트 이름이 공개 evidence JSON이나 README에 기록되지 않았는지 확인한다.
