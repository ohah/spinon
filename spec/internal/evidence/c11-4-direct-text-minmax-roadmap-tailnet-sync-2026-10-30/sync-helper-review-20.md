# Tailnet 동기화 helper 적대 검토 20관점

검토 대상: `prepare-selected-root.mjs`, `complete-selected-build.mjs`, `sync-tailnet.mjs`, 선택 빌드 설정 및 생성 manifest. 검토는 실제 파일 내용을 대상으로 했으며, 시뮬레이터/제품 동작 검증으로 확대하지 않는다.

| # | 실패 관점 | 확인 결과 |
|---:|---|---|
| 1 | 다른 커밋에서 선택 파일을 섞음 | 선택 단계가 `HEAD == origin/main`을 요구하고 커밋과 tree를 manifest에 기록한다. |
| 2 | 추적 중인 미커밋 문서를 원본으로 사용 | 선택 단계가 tracked 변경을 거부한다. 기존 미추적 자료는 선택 경로 밖이며 stage하지 않는다. |
| 3 | 기존 선택 root를 덮어씀 | root 및 manifest가 이미 있으면 즉시 중단하고 `wx`로 새 manifest를 쓴다. |
| 4 | 미등록 파일을 무심코 전체 공개 | 원본 경로 목록을 코드에 명시하고 선택 manifest에 경로별 해시를 기록한다. |
| 5 | alias가 같은 출력 경로를 덮어씀 | 복사 때 목적지 중복을 거부한다. |
| 6 | 소스 심볼릭 링크를 따라감 | 소스 파일과 재귀 디렉터리에서 `lstat` 및 symlink 거부를 확인했다. |
| 7 | 생성된 root 파일이 변조됨 | 원본과 선택 복사본의 바이트 수·SHA-256을 대조한다. |
| 8 | URL 경로가 출력 root 밖으로 나감 | 각 alias 목적지의 정규 문자열 경계를 검사하고 중복·빈 경로를 거부한다. |
| 9 | 예전 RSPress 출력이 새 빌드로 오인됨 | 실행 전 출력 경로가 비어 있었음을 이전 단계에서 확인했고, 빌드 로그와 새 manifest가 남아 있다. |
| 10 | 필수 문서 route가 빠짐 | 로드맵, STATUS, 계약, 계획, fixture 및 캡처 경로를 필수 목록으로 검사한다. |
| 11 | 잘못된 완료 상태를 미리보기로 노출 | 로드맵/STATUS에서 PR, merge SHA, `72/213`, `42/42`, `129/129` marker를 검사한다. |
| 12 | 출력 symlink 또는 비정규 파일을 배포 | 출력 전체를 재귀 순회하며 symlink와 미지원 항목을 거부한다. |
| 13 | 엉뚱한 서버에 복사 | 포트 8768 listener 하나와 프로세스 인자를 확인한다. |
| 14 | 외부 공개 listener를 대상 서버로 착각 | listener 주소를 `127.0.0.1:8768`로 제한하고 예상하지 않은 네트워크 handle이면 중단한다. |
| 15 | 대상 root 내부 symlink를 따라가 외부 파일을 덮음 | 대상 root와 각 경로 구성요소를 `lstat`하고 symlink를 거부한다. |
| 16 | 경로 traversal 또는 역슬래시 경로 사용 | 절대 경로, 빈 segment, `.`·`..`, 역슬래시를 거부한다. |
| 17 | preflight 뒤 원본이 바뀜 | 복사 직전 선택 출력의 바이트 수와 SHA-256을 다시 확인한다. |
| 18 | preflight 뒤 대상이 바뀜 | 복사 직전 대상 존재 여부와 이전 해시를 다시 대조한다. |
| 19 | 기존 대상 덮어쓰기 전 백업 실패 | 백업은 `wx`로 생성하고 크기와 해시가 사전 관측값과 일치해야 진행한다. |
| 20 | 중단된 복사가 조용히 성공으로 보고됨 | 개별 파일은 임시 파일 후 rename하고 즉시 해시를 확인한다. 최종 검증은 123개 로컬·원격 응답과 백업 8개를 모두 확인한다. 다중 파일 전체를 한 번에 원자적으로 바꾸지는 않으며, 중간 실패 시 생성된 백업으로 수동 복구할 수 있다. |

추가 경계: preflight와 copy 사이에 동시에 대상 파일을 바꾸는 외부 프로세스가 있으면 해당 항목에서 실패한다. 디렉터리 단위의 다중 파일 rollback은 자동화되어 있지 않다. 실제 동기화에서는 사전 상태 재확인, 교체 전 백업, 파일 단위 원자 교체, 전체 사후 해시 검증을 통과했다.
