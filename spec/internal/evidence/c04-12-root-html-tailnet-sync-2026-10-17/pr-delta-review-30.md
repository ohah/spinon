# C04.12 Tailnet 동기화 PR 변경 검토

기준: PR #271의 정적 증거 파일 추가. 앱 런타임, CSS 동작, 구현 상태 대장은 변경하지 않는다. 각 관점은 공개 미리보기의 오표시·파일 유실·근거 과장을 막는 실패 경로를 확인한다.

| # | 실패 관점 | 확인과 판정 |
|---:|---|---|
| 1 | 오래된 소스 커밋을 게시하는가 | 최종 manifest와 검증 기록이 `f43a04ff...`를 가리키며 #270 병합 후 빌드했다. 통과 |
| 2 | 빌드 도구 버전이 바뀌어 재현성이 흐려지는가 | 로그에 Rspress `2.0.22`가 남아 있고 버전 갱신은 없다. 통과 |
| 3 | 빌드 실패를 성공으로 기록하는가 | 저장된 로그 끝의 종료 코드는 0이며 web/node 렌더 완료가 보인다. 통과 |
| 4 | dist 자동 정리 경고가 산출물을 오염시키는가 | 경고를 문서화했고 별도 출력 경로와 파일별 manifest를 사용했다. 전체 clean-build로 확대 주장하지 않는다. 통과 |
| 5 | 선택 빌드가 전체 strict build로 오인되는가 | README와 빌드 결과에서 선택 빌드이며 전체 strict build/dead-link 검사가 아니라고 한정했다. 통과 |
| 6 | 임시 빌드 설정이 제품 설정처럼 남는가 | `.rspress.tailnet.config.ts`는 임시 파일이며 PR에 포함하지 않는다. 통과 |
| 7 | manifest의 파일 수가 복사 기록과 다른가 | 최종 manifest, preflight, copy, served 기록 모두 68개를 대상으로 한다. 통과 |
| 8 | 파일 길이와 digest가 누락되는가 | 최종 manifest가 각 경로의 길이와 SHA-256을 기록한다. 통과 |
| 9 | 파일 복사 중 일부만 반영되는가 | 복사 검증에서 변경 2개, 동일 66개, 총 68개가 일치한다. 통과 |
| 10 | 사전 검사와 실제 게시 소스가 다른가 | preflight와 served 기록 모두 동일한 기준 커밋과 preview URL을 기록한다. 통과 |
| 11 | 게시 과정에서 기존 파일이 무단 삭제되는가 | preflight와 final manifest의 삭제 집합은 비어 있다. 통과 |
| 12 | 교체 파일을 복구할 백업이 없는가 | 첫 동기화의 4개와 counter 정정의 2개 교체 백업 검증 JSON을 보존했다. 통과 |
| 13 | 백업을 새 파일로 오인하는가 | README가 첫 교체 4개와 후속 교체 2개를 별도 단계로 기록한다. 통과 |
| 14 | 오래된 `61/197` 집계를 현재값으로 노출하는가 | 동기화된 roadmap에서 고정 숫자를 제거했고 브라우저 확인에서 stale 문구 부재를 기록했다. 통과 |
| 15 | 동적 공식 집계가 다른 시점에 잘못 읽히는가 | 확인 시점의 공식 counter는 `71/205`이며 검증 JSON에 시간을 기록했다. 통과 |
| 16 | 205개 분모의 분해가 빠지는가 | 브라우저 검증은 상위 78, ID 세부 125, ID 없는 하위 체크 2를 기록한다. 통과 |
| 17 | 숫자 문서 변경이 STATUS 완료 처리를 암시하는가 | README와 PR 설명은 STATUS 체크박스를 바꾸지 않았고 C04.12가 미완료임을 명시한다. 통과 |
| 18 | Tailnet 화면에서 C04.12가 완료처럼 보이는가 | 브라우저 확인에서 해당 항목 상태는 `미완료`로 확인됐다. 통과 |
| 19 | roadmap만 열리고 계획 링크가 깨지는가 | Agent Browser에서 계획 경로가 열리고 C04.12 및 html5ever 내용을 확인했다. 통과 |
| 20 | 내부 계약 링크가 깨지는가 | `0077` 계약 경로가 로드되고 문서 제목과 C04.12 내용을 확인했다. 통과 |
| 21 | 비교 근거 README 링크가 깨지는가 | 근거 README가 로드되고 본문을 확인했다. 통과 |
| 22 | 근거 화면의 Chrome oracle 이미지가 404/깨짐인가 | 두 이미지 모두 로드되고 각 1170×2532 intrinsic 크기를 확인했다. 통과 |
| 23 | PR에 첨부한 동기화 스크린샷 경로가 틀리는가 | PR 번호별 `refs/pull/.../head` raw URL로 PR 화면에서 각각 확인한다. PR 생성 후 판정 예정 |
| 24 | local preview 응답이 실패하는가 | 68개 모두 HTTP 200, 길이·SHA-256 일치로 기록됐다. 통과 |
| 25 | Tailnet 응답이 실패하는가 | 68개 모두 HTTP 200, 길이·SHA-256 일치로 기록됐다. 통과 |
| 26 | 로컬 제공물이 파일 manifest와 다르게 변형되는가 | local byte length와 SHA-256 비교가 68/68 통과다. 통과 |
| 27 | Tailnet 제공물이 로컬 manifest와 다르게 변형되는가 | Tailnet byte length와 SHA-256 비교가 68/68 통과다. 통과 |
| 28 | 게시 검증이 앱 동작 검증으로 과장되는가 | README는 문서 미리보기 근거이며 앱 렌더 및 플랫폼 기능 검증이 아니라고 선을 그었다. 통과 |
| 29 | listener 재시작이나 tmux 변경이 사용자 환경을 흔드는가 | 기록은 listener PID 1191 유지 및 tmux 미변경을 명시한다. 통과 |
| 30 | Agent Browser가 검증 뒤 계속 실행돼 리소스를 남기는가 | 전용 세션을 닫고 세션 프로세스가 끝났는지 확인한 뒤 결과를 기록한다. PR 이미지 확인 뒤 최종 판정 예정 |

미해결 검토 관점은 PR 이미지와 브라우저 종료 확인 후 이 문서에서 최종 판정한다. 현재 확인 근거의 한계는 문서 빌드 범위와 C04.12 미완료 상태다.
