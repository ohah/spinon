# C12.3 병합 상태 문서 동기화 검토

PR #136의 실제 병합 상태와 저장소의 공식 상태·내부 명세·로드맵 표기를 대조했다. 기능이나 지원 범위를 새로 주장하지 않는다.

| 번호 | 실패 관점 | 확인 및 수정 |
|---:|---|---|
| 1 | PR #136이 실제로 열려 있는데 문서만 병합됐다고 적는가 | GitHub가 PR #136을 `MERGED`로 표시하는 것을 확인하고 병합 상태로 기록했다. |
| 2 | 공식 상태 대장의 C12.3 체크가 실수로 해제되는가 | 완료 체크를 유지했다. 변경은 PR 상태 문구에 한정했다. |
| 3 | C12.3 완료를 상위 C12 완료로 확대하는가 | 상위 C12는 미완료로 남고 C12.4·C12.5도 미완료로 유지된다. |
| 4 | 내부 계약 0057이 아직 검토 중이라고 남는가 | 계약 상단의 PR 상태를 리베이스 병합으로 바꿨다. |
| 5 | 내부 계약 색인에 과거 PR 상태가 남는가 | `spec/internal/README.md`의 0057 행도 병합 상태로 맞췄다. |
| 6 | 공개 로드맵 링크가 병합 후에도 미검토를 암시하는가 | 링크 문구를 병합 PR의 구현 근거를 가리키도록 수정했다. |
| 7 | C12 단계 계획이 C12.3 결과를 누락하는가 | C12.3 PR #136을 리베이스 병합 목록에 넣고 C12.4를 다음 단계로 유지했다. |
| 8 | 변경이 C12.3의 CSS 지원 범위를 넓혀 보이게 하는가 | 제한 `RuntimeBlockPositioningV1` profile 표현과 미지원 경계를 그대로 유지했다. |
| 9 | 전체 79개 노드를 모바일에서 실행했다고 읽히는가 | 28-node parent-closed subset 및 전체 79-node 미실행 한계를 유지했다. |
| 10 | Chrome 비교 수치가 양 플랫폼 전체 동등성으로 과장되는가 | 13개 상태·364개 frame과 `0.009375 CSS px` 최대 차이의 기존 범위를 바꾸지 않았다. |
| 11 | Android 검증이 에뮬레이터로 잘못 표기되는가 | Android SM-S731N 실기기와 Android 16/API 36 조건을 유지했다. |
| 12 | iOS 시뮬레이터 결과가 실기기 결과로 바뀌는가 | iPhone 17 Pro / iOS 26.2 Simulator 표기를 유지하고 iOS 실기기는 미검증으로 남겼다. |
| 13 | 측정 허용치나 기준 Chromium이 바뀌는가 | Chrome 154와 기존 `0.5 CSS px` 허용치를 그대로 보존했다. |
| 14 | fixed 구현을 stacking 또는 paint-order 완료로 오인하는가 | scroll·stacking·paint-order는 여전히 범위 밖이라고 명시했다. |
| 15 | WPT 미실행 한계가 사라지는가 | WPT 전체 미실행 문구를 유지했다. |
| 16 | 계약 문서 ID를 계약 버전으로 오해하는가 | 문서 ID `0057`과 숫자 계약 버전 `0.1.0`을 변경하지 않았다. |
| 17 | 내부 계약이 공개 API로 승격된 듯 보이는가 | `공개 API 아님` 및 공개 CSS/API 전체 완료가 아니라는 문구를 유지했다. |
| 18 | C07.2의 별도 완료 상태가 C12.3 수정에 섞이는가 | C07.2 상태와 Android 보조 근거는 수정하지 않았다. |
| 19 | 공개 로드맵의 동적 상태가 feature branch를 조회하는가 | 저장소 원본 URL이 `ref=main`인지 확인했다. Tailnet 생성 산출물에는 오래된 feature branch URL이 남아 있어 현재 별도 미리보기 갱신 대상으로 확인했다. |
| 20 | 이 문서 변경이 GitHub Pages를 배포하거나 tailnet 미리보기 동기화를 건너뛰는가 | GitHub Pages 실행은 하지 않는다. Tailnet은 저장소 원본을 다시 빌드한 뒤 별도로 확인해야 하며, 현재 변경만으로 동기화됐다고 주장하지 않는다. |

## 확인한 경계

- GitHub에서 PR #136은 리베이스 병합 상태다.
- 변경된 상태 표기는 `spec/STATUS.md`, 내부 계약 0057, 내부 계약 색인, C12 단계 계획, 공개 로드맵에서 서로 일치한다.
- Tailnet의 기존 생성 산출물은 `ref=feat/c12-3-fixed-runtime`을 포함해 저장소 원본과 달랐다. 산출물 재생성·실제 Tailnet 확인은 문서 변경과 별도의 운영 단계다.
