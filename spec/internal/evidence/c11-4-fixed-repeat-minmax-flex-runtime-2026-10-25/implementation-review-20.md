## 판정

최종 API 37 ARM64 Android AVD와 iPhone 17 Pro/iOS 26.2 Simulator에서 각각 6/6 scene의 frame·track trace·draw/present 검사를 통과했고, 최신 Android/iOS run의 26개 입력 해시가 현재 source와 모두 일치한다. 초기 Java brace 빌드 실패와 pre-provenance 캡처는 수정·대체된 과거 진단이다. 앱 단독 adapter assertion은 완화되어 있어 외부 runner가 필요하다. #5의 full-rect geometry와 root 크기는 독립 Chrome observation에 직접 결합됐고 focused FFI test 1/1 통과했다. MinMax reservation recovery는 실패 injection을 포함한 Rust 단위 테스트로 보강됐다. 최신 final-source Rust static archive는 product 0/6·fixture-test positive control 6/6이었고 26개 입력 hash 및 실행 시점 tracked diff가 iOS run과 build 전후 일치한다. 앱 bundle/제품 APK·IPA 제외는 검증되지 않았다.
