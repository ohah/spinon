## Verified and remaining boundaries

- Stored Android Gradle and iOS Simulator builds succeeded; both app runs passed the runtime matchers and produced matching frames/trace. The successful artifacts are fixture-test Debug builds only.
- Stored evidence reports Rust focused `generic_direct_text` 9/9 and FFI source test 1/1. The Rust implementation observation records broader `c11_4` 34/34 and `c114` 19/19, formatter and targeted Clippy results. This review did not rerun those commands.
- The runtime traces observe `layoutInputRevision.intrinsicSize=0`; the matcher contract checks a HostDocument source and valid nonnegative revisions rather than requiring an exact zero. This is consistent with the scene having no image intrinsic resource.
- Product CSS admission, Release artifact fixture exclusion, all 13 legacy fallback scenes, remote PR/CI, glyph painting, Stage B/C/D and full C11.4 remain unverified/out of scope. Official C11.4 remains incomplete at `72/213`.

- **Low:** Before treating this run as commit-bound source evidence, record a dirty-source fingerprint (or rerun under a new immutable run ID after commit) in addition to `source-head.txt`. The APK and screenshot hashes in the current runtime README are already synchronized with the saved artifacts. Mark or refresh the older targeted static matcher report, whose source hashes and Rows statement no longer describe the current checkout.
