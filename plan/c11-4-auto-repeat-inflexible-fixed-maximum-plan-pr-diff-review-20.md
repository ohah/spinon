# C11.4 fixed-maximum auto-repeat 계획 PR 변경 · 적대적 검토 20개

검토 대상은 계획만 포함하는 PR 변경이다. 계획 실패 관점 20개 검토와 별도로 변경 파일, 고정 oracle 산출물, 상태 장부와 범위 선언을 확인했다.

| # | 변경에서 확인한 실패 경로 | 검토 결과 |
|---:|---|---|
| 1 | 계획 PR에 제품 계산 로직이 섞일 수 있음 | 변경 파일은 계획·검토·상태 설명·fixture·oracle 근거다. Rust/CSS 구현 변경은 없다. 통과. |
| 2 | 계획 승인만으로 공식 C11.4 상태를 완료 표시할 수 있음 | `STATUS.md`의 C11.4 checkbox는 바뀌지 않고 계획 단계라고 기록한다. 통과. |
| 3 | 전체 공식 완료 수를 조용히 올릴 수 있음 | C11.4 기록은 `72/213`을 유지하고 완료 수 집계 항목은 바꾸지 않는다. 통과. |
| 4 | 공식 상태 설명이 C11이 아닌 다른 roadmap 항목에 들어갈 수 있음 | 새 설명은 C11.4 기록 뒤, C12 제목 앞에 있다. 통과. |
| 5 | 상위 계획이 새 단독 계획이나 검토 파일을 잘못 연결할 수 있음 | 상대 경로 두 개가 추가한 계획과 계획 검토 파일을 가리킨다. 통과. |
| 6 | fixed-maximum 지원 범위를 unsupported 값까지 과장할 수 있음 | 계획은 flex/auto/intrinsic 최대값, 임의 calc, definite하지 않은 기준 크기, 다중 자동 반복, 일반 공개 CSS 허용을 계속 거부한다고 명시한다. 통과. |
| 7 | fixed maximum이라는 용어가 길이만 뜻해 백분율/calc 근거와 충돌할 수 있음 | 범위와 표에서 `LengthPx`, definite 기준 크기의 백분율, 제한된 타입형 calc를 구분한다. 통과. |
| 8 | 49 scene 분해 합계가 실제 개수와 다를 수 있음 | `36 + 6 + 2 + 1 + 4 = 49`이고 fixture ID 집합 및 verifier 결과와 맞는다. 통과. |
| 9 | 원본 브라우저 관측이 최종 fixture 내용과 다를 수 있음 | verifier가 fixture SHA, 정확한 scene ID 집합, scene 필드, 트랙, frame을 검사하고 49/49 통과한다. 통과. |
| 10 | 반복 수 공식에서 반복 트랙 사이 gap이 빠질 수 있음 | 단일 트랙 및 두 트랙 공식에 각각 `n−1`, `2n−1`개 gap을 포함하며 Chromium 관측과 맞는다. 통과. |
| 11 | percentage 최대값을 border box 기준으로 계산할 수 있음 | fixture padding/border는 0이며 content dimension은 고정했다. 관측과 독립 계산은 130px content 기준 크기를 사용한다. 통과. |
| 12 | `auto-fit` collapse를 배치 전 반복 수 계산과 혼동할 수 있음 | 원본 CSSOM은 빈 트랙을 0으로 표시하고 계획은 반복 수와 collapse를 분리한다. 통과. |
| 13 | 두 트랙 pattern 화면이 원본 관측과 다를 수 있음 | 마지막 네 두 트랙 사례를 추가한 뒤 화면과 JSON을 다시 수집했고 화면 hash를 기록했다. 통과. |
| 14 | oracle 수집 후 브라우저 세션이 남을 수 있음 | 이름이 지정된 세션의 종료를 기록했고 마지막 조회는 `active=false`, `pid=null`이다. 통과. |
| 15 | 사용자 정의 Chrome fixture를 WPT 통과로 오해할 수 있음 | README는 이를 Chromium oracle로 부르고 Spinon WPT 통과가 아니라고 밝힌다. 통과. |
| 16 | 계획 검토를 PR 변경 검토 횟수에 중복 집계할 수 있음 | 계획 검토와 PR 변경 검토 파일은 서로 다른 실패 관점을 다룬다. 통과. |
| 17 | PR artifact에 무관한 기존 untracked evidence가 섞일 수 있음 | 계획 변경에 필요한 경로만 stage하며 기존 untracked 파일은 stage하지 않는다. 통과. |
| 18 | screenshot이 손상됐거나 관측값과 일치하지 않을 수 있음 | 요약 PNG는 1280×633의 유효한 PNG다. verifier가 그림에 표시한 여섯 CSSOM 문자열을 원본 관측 JSON과 대조하고, PR 본문은 이 요약 화면을 raw GitHub image link로 표시한다. 통과. |
| 19 | 계획이 내부 계약/API version 승격을 암시할 수 있음 | 계약 버전이나 공개 API 상태를 바꾸지 않고 C11.4와 C11을 미완료로 둔다. 통과. |
| 20 | 계획 검토와 계획 PR 병합 전에 구현을 시작할 수 있음 | 별도 계획 검토 20개를 마쳤고 구현 파일은 이 변경에 없다. 구현 착수는 계획 PR 병합 뒤로 제한한다. 통과. |

**결과:** 통과 20/20, 미해결 사항 0개. 화면 파일 형식과 링크 경로를 확인한 뒤 영향을 받은 관점도 다시 확인했다.
